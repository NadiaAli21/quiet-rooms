# 🌙 Quiet Rooms — *Alone Together*

> A cozy, zero-pressure virtual sanctuary and silent co-working space designed specifically for introverts.

🔗 **Live Demo:** [https://nadiaali21.github.io/quiet-rooms/](https://nadiaali21.github.io/quiet-rooms/)

---

## ✨ Philosophy

Most online productivity and co-working platforms rely on cameras, microphones, or verbal check-ins—draining the exact social battery introverts need to get deep work done. On the flip side, standalone ambient sound apps can feel completely isolating.

**Quiet Rooms** bridges that gap through **low-demand parallel play**: the comforting presence of working alongside others in a quiet library, without the performance tax of being "on."

---

## 🌿 Key Features

* **Zero-Friction, Account-Free Entry:** Drop in immediately with an auto-generated cozy alias (e.g., *QuietFox*, *MistyOwl*), a custom avatar icon, and a quiet activity tag—no sign-ups, cameras, or microphones.
* **Social Battery & Mood-Adaptive UI:** Slide your current energy level between *Deep Silence*, *Gentle Company*, and *Open to Break Chat* to dynamically shift the room's color palette and ambient lighting between midnight blue, soft sage, and warm amber.
* **Procedural Web Audio Soundboard:** Mix custom background atmospheres—*Gentle Rain*, *Warm Hearth*, *Deep Brown Hum*, and a *Midnight Pad*—synthesized live in the browser via the Web Audio API with zero external audio dependencies.
* **Gentle Flow Timer:** Features 25-minute, 50-minute, and 10-minute presets with a visual progress ring and a soft singing-bowl chime on completion.
* **Passive Room Presence & Silent Glows:** See fellow quiet workers in the room and send an anonymous warm glow (`✦`) without initiating conversation.
* **Time-Gated Break Whisper Chat:** Chat stays gently locked during focus sessions to protect flow state, unlocking only during scheduled breaks.
* **Auto-Saving Private Scratchpad:** A local mind-dump space saved directly in your browser's `localStorage` so distracting thoughts never leave your device.

---

## 🛠️ Built With

* **HTML5** — Semantic structure and accessible controls
* **CSS3** — CSS custom properties for mood-adaptive theming, glassmorphism surfaces, and responsive CSS Grid layout
* **Vanilla JavaScript (ES6+)** — Procedural sound synthesis (Web Audio API), timer state management, and `localStorage` persistence
